## ☁️ Modelos de Implantação
- **On-Premise**: Infraestrutura local
- **Cloud**: Totalmente hospedado na nuvem
- **Hybrid**: Combinação de infraestrutura local e nuvem

## 🖥️ Plataformas e Serviços
- **Infra as a Service (IaaS)**
- **AWS (Amazon Web Services)**
- **Azure (Microsoft)**
- **Oracle Cloud**
- **GCP (Google Cloud Platform)**
- **Region + Zones**: Estrutura de distribuição geográfica

## 🌐 Modelos de Nuvem
- **Nuvem Privada**: Uso exclusivo por uma única organização
- **Nuvem Pública**: Entrega de serviços a múltiplos clientes
- **Nuvem Híbrida**: Integra nuvens públicas e privadas para melhor flexibilidade
